## 买美国 VPS 前，先定三件事

搜索“美国 VPS 购买”的人，事后后悔的原因基本集中在三个地方：线路选错、流量口径没看清、续费价被忽略。这三件事想清楚了，再看具体套餐就是顺着挑，而不是被营销页牵着走。

### 线路：CN2 GIA、CN2 GT、AS9929、AS4837 差在哪

先说大前提：从国内访问，国内机房最快，其次是香港、日本、韩国、新加坡这些周边地区，美国机房本来就排在再后面一档。选美国 VPS，等于主动接受了更远的物理距离，所以线路优化才格外重要。

一般情况下的线路排序是：CN2 GIA > AS9929 > AS4837 > CN2 GT。CN2 GIA 全程走优化线路，晚高峰最稳；CN2 GT 只在部分路段走 CN2，骨干段该挤还是挤。具体到你身上表现如何，还要看本地网络。落到选择上就一条规则：给国内用户建站、跑远程桌面、对延迟敏感的，优先 CN2 GIA；只挂爬虫、跑脚本、主要给海外用户访问的，普通线路足够，没必要为用不到的线路多花钱。

### 流量口径：500GB 月流量和 1Mbps 不限量，差别比你想的大

对比套餐时，流量那一栏必须看清是“月流量”还是“不限流量但限速”。下文提到的方案均为独立 IP，流量按月计算；而有些国内云的低价款写的是 1Mbps 带宽不限流量——1Mbps 跑满一整月，理论上限约 324GB，还不如明明白白给 500GB/月、1Gbps 带宽的方案。看着“不限”，实际天花板更低，这类文字游戏在付款前要拆穿。

## 低价年付和“免费 VPS”的坑

便宜方案的真实成本，要看三个数字：首期价、续费价、计费周期。少看一个，第二年账单就会给你上一课。

**续费价陷阱。** 以 Navicosoft 纽约 V1 为例，月付 $12，年付打九折到 $10.80/月，但续费按 $12/月的原价走——第一年 $129.60，第二年就是 $144。付款前翻一下价格页角落里的 "Renews at" 字样，比看首页大字有用。

**虚拟技术选择。** 优先 KVM，其次 Xen，最后 OpenVZ；这个排序基本也是价格从高到低的排序。看到异常低价的 OpenVZ 方案，先想清楚超售风险自己能不能接受。

**免费美国 VPS 的真相。** 大多数“免费 VPS”要么是骗局，要么靠收集并出售你的信息来覆盖成本——你不为服务付费的时候，你自己就是产品；而且资源限制重重，超了就得升级付费。想真正白嫖，正路是新用户注册 Amazon Lightsail：3 个月免费的 1 核 2GB / 60GB SSD / 3TB 流量方案，Linux 和 Windows 都能选，还附带每月 1TB 的永久免费 CDN 流量。

**备份习惯。** 任何 VPS 都有挂掉的可能，商家跑路、母鸡故障、数据丢失都不是小概率事件。定时备份数据才是王道，这条比选哪家都重要。

**支付方式。** 下单前确认支持的付款渠道：部分商家支持支付宝直接付款，其余多以 PayPal 或信用卡为主；个别商家（比如 BuyVM）要求账户信息与 PayPal/支付宝实名一致，审核较严，材料不齐会被拒。

## 常见问题

**月付还是年付划算？** 年付单价明显更低，不少 $10 级方案甚至只提供年付。前提是商家靠谱：拿不准的商家先月付试用一两个月，确认稳定再转年付；而 $10 级年付本身就压低了试错成本，直接年付也不至于伤筋动骨。

**美国 VPS 需要备案吗？** 不需要。ICP 备案针对的是解析到中国大陆服务器的域名，机房在美国就不涉及备案流程，域名解析过去就能用。

**美国选哪个位置的数据中心好？** 从国内访问看，西海岸（洛杉矶、硅谷）物理距离更近，延迟通常低于东海岸。这也解释了为什么 CN2 GIA 方案普遍把洛杉矶作为主打机房，LightNode 也把节点放在硅谷和华盛顿两地。
